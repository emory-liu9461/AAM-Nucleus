# Nucleus brand

| File | Use |
|---|---|
| `nucleus-logo.svg` | Full logo for light backgrounds |
| `nucleus-logo-white.svg` | Full logo for dark backgrounds or photos |
| `nucleus-mark.svg` | Symbol only (nucleus + baseball) |
| `nucleus-icon.svg` | App icon / favicon: white mark on a blue rounded square |

**Colors:** Nucleus Blue `#0A4FA3` · Seam Red `#E4343A` · White `#FFFFFF`

The wordmark is lettered in *Yellowtail* (Astigmatic, Apache License 2.0), converted to outlines,
so no font is needed to display it. All artwork is original. It's inspired by classic baseball
script lettering, and doesn't copy any team's logo.
